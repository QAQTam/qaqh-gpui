## 实现边界

- Linux x86_64 / Wayland；其它平台尚未列入正式支持范围。
- 命令能力清单覆盖当前 46 条命令，其中 35 条提供入口或由 SDK 使用。延后/排除项逐项说明原因，不以“全支持”概括。
- 侧栏检索当前后端返回的最近 256 条会话；消息搜索在已加载的当前会话内进行。
- 前端不持久化业务快照；草稿与桌面布局独立保存，业务状态始终通过 RingingV2 重建。
- 发布源固定到 `packaging/dependencies.json` 的版本，并应用后端原生修正。当前本机其它未提交后端改动被保留；本地候选包记录准确源码与差异，便于复核。
- CI 定义已加入，远端 CI 尚未触发；本轮以本机可重复执行的验证结果作为证据，不声称远端流水线已通过。
