## 1. Google Sans（UI 主字体）

- **文件**：`GoogleSans-Regular.ttf`、`GoogleSans-Medium.ttf`、`GoogleSans-SemiBold.ttf`、`GoogleSans-Bold.ttf`
- **来源**：`https://github.com/googlefonts/googlesans`（Google Fonts 官方静态 TTF）
- **版权声明**：`Copyright 2025 The Google Sans Project Authors`
- **许可证**：SIL Open Font License, Version 1.1（完整正文见 [OFL-GoogleSans.txt](OFL-GoogleSans.txt)）

## 2. Google Sans Code（终端与代码等宽字体）

- **文件**：`GoogleSansCode-Regular.ttf`、`GoogleSansCode-Bold.ttf`、`GoogleSansCode-Italic.ttf`
- **来源**：`https://github.com/googlefonts/googlesans-code`（Google Fonts 官方静态 TTF）
- **版权声明**：`Copyright 2025 The Google Sans Code Project Authors`
- **许可证**：SIL Open Font License, Version 1.1（完整正文见 [OFL-GoogleSansCode.txt](OFL-GoogleSansCode.txt)）

## 分发说明（SIL OFL 1.1）

- 上述字体文件未经修改地随二进制打包分发，不单独作为独立商品售卖，且完整保留版权声明与 `OFL-*.txt` 授权正文。
- 中日韩（CJK）字符在运行时自动回退至用户本机已安装的系统字体，本目录不含 CJK 字体文件。
